===============================================================================
小微企业信贷违约风险评估与可视化风控系统
===============================================================================

项目说明
-------------------------------------------------------------------------------
本系统是一个面向小微企业信贷违约风险评估的交互式模型，提供：
- 自适应模型训练（集成 IV/WOE 筛选、VIF 剔除、LR/XGB/LGB 基模型 + Stacking 融合）
- Streamlit 风控驾驶舱（单体评估、全域大屏、模型监控、数据管理、SHAP 可解释性）
- 单体、批量预测与历史记录管理
- SHAP 模型可解释性图表生成

系统采用“训练‑部署”分离架构，训练完成后所有模型文件统一存放于 models/ 目录，
前端自动加载；SHAP 图表存放于 shap_images/ 目录，供前端展示。

运行环境
-------------------------------------------------------------------------------
- Python 3.11 或更高版本（推荐 3.11）
- 操作系统：Windows / macOS / Linux

快速开始（本地部署）
-------------------------------------------------------------------------------
1. 安装依赖
   pip install -r requirements.txt

2. 数据准备
   csv格式数据（应变量应为二分类变量即是否违约）

3. 训练模型
   启动前端（streamlit run app.py），进入“模型训练”页面上传 CSV 并配置特征与参数，
   点击“保存配置”后，在终端执行：
   python train.py
   系统将自动读取 temp_config.json 并开始训练。

   训练完成后，所有产物将保存在 models/ 目录下（详见下方“目录结构”）。

4. （可选）生成 SHAP 可解释性图表
   在终端执行：python shap_analysis.py
   该脚本会加载 models/ 中的模型及数据，生成图表并存入 shap_images/ 目录。

5. 启动 Streamlit 前端
   streamlit run app.py（再次在终端执行）
   访问 http://localhost:8501 使用系统。



目录结构及文件说明
-------------------------------------------------------------------------------
本项目根目录下的主要文件夹及文件作用如下：

/ （根目录）
├── app.py                     # Streamlit 主前端应用（风控驾驶舱）
├── train.py                   # 自适应模型训练脚本（含 IV/WOE/VIF 筛选、Stacking）
├── shap_analysis.py           # SHAP 可解释性分析脚本（生成 PNG 图表）
├── predict.py                 # 模型预测封装函数（供 app 和 fastapi 调用，可选）
├── utils.py                   # 通用工具函数（IV/WOE/VIF/数据预处理，可选）
├── make_synthetic.py          # 合成数据生成器（可选）
├── requirements.txt           # Python 依赖清单
├── readme.txt                 # 本文件
│
├── models/                    # 存放训练产出的所有模型文件（由 train.py 自动创建）
│   ├── base_models_tuned.pkl  # 训练好的基模型（LR/XGB/LGB）及 Stacking 元模型
│   ├── scaler_lr.pkl          # LR 特征标准化器
│   ├── woe_maps.pkl           # 各特征的 WOE 编码映射（含连续变量分箱）
│   ├── lr_features.pkl        # LR 模型使用的特征列表（WOE 处理后）
│   ├── tree_features.pkl      # 树模型使用的特征列表（独热编码后）
│   ├── best_threshold.pkl     # 最优分类阈值（Youden 指数）
│   ├── config.json            # 训练配置（特征列、目标列、超参数等）
│   ├── categorical_options.json # 分类变量所有可能取值（供前端下拉菜单）
│   └── model_performance.csv  # 各模型在测试集上的性能指标（AUC/KS/F1 等）
│
├── shap_images/               # SHAP 分析生成的图表（由 shap_analysis.py 自动创建）
│   ├── shap_xgb_summary.png   # XGBoost 全局特征重要性（散点图）
│   ├── shap_xgb_bar.png       # XGBoost 特征重要性排序（柱状图）
│   ├── shap_xgb_waterfall.png # XGBoost 高风险样本拆解（瀑布图）
│   ├── shap_stacking_summary.png # Stacking 元模型 SHAP 摘要（如可用）
│   └── shap_stacking_waterfall.png # Stacking 高风险样本解释（如可用）
│
├── predictions_history/       # 批量预测历史记录（由 app.py 自动创建）
│   └── pred_*.parquet/json    # 每次批量预测的 Parquet 数据及元信息
│
└── temp_train_data.parquet    # 临时训练数据缓存（前端上传时生成）
    temp_config.json           # 前端生成的训练配置（供 train.py 读取）

注意事项
-------------------------------------------------------------------------------
1. 训练数据要求：
   - 目标列须为二分类（0/1，0=正常，1=违约）。
   - 分类变量建议预先进行编码或保持字符串类型（系统自动处理）。

2. 模型加载失败处理：
   - 请确认 models/ 目录下存在上述所有 .pkl 和 .json 文件。
   - 使用前端训练，确保训练完成后没有移动或删除模型文件。
   - 可尝试删除 models/ 目录后重新训练。

3. WOE 实现说明：
   本模型使用“目标均值编码”近似实现 WOE，满足快速原型迭代需求。
   如需严格金融风控生产标准（分箱/IV 精确计算），请替换 train.py 及 utils.py 中的相关函数。

4. 性能优化：
   - 训练时若数据量超过 20 万行，系统会自动抽样至 20 万行以内，以保证训练速度。
   - 前端 SHAP 图片加载依赖 shap_images/ 目录，若缺失则提示运行 shap_analysis.py。

5. 本系统为模型演示版本，未包含用户认证、日志审计等生产级功能，部署时请自行补充。

技术支持
-------------------------------------------------------------------------------
如有问题，请查阅各脚本开头的注释，或根据终端错误信息定位。
您也可以根据业务需求调整 config.json 中的参数（如 IV 阈值、VIF 阈值等）后重新训练。
